CyberShield – Cybersecurity Awareness Platform

Built by MUSTAPHA AYATULAI OLAMIDE

About the Project

CyberShield is a personal project I built to combine my interest in cybersecurity with my learning journey in frontend web development.

As someone learning cybersecurity, I believe understanding how websites work is an important skill. It helps me appreciate how users interact with online platforms and why security awareness matters in our everyday digital lives.

I created CyberShield to make learning about common cyber threats simple and interactive. The website introduces users to threats such as phishing, malware, social engineering, and weak passwords, while encouraging them to develop safer online habits.

Why I Built It

Many people use the internet every day without knowing how easily they can fall for a fake email, suspicious link, or online scam. I wanted to build something that presents basic cybersecurity information in a way that is easy to understand and explore.

This project also gave me an opportunity to practise what I have been learning in frontend web development and apply those skills to a topic I am genuinely interested in.

What You Can Do on CyberShield

- Explore cyber threats: Learn about common attacks and how they can affect internet users.
- Search and filter: Find specific threats using the search bar and category filters.
- Check password strength: Test a sample password using a basic strength checker.
- Take a cybersecurity quiz: Test your knowledge and learn how to respond to suspicious messages.
- Use it on different devices: The website is designed to work on desktop and mobile screens.

Technologies I Used

- HTML5 for the structure of the website.
- CSS3 for the design, layout, and responsive styling.
- JavaScript ES6 for the interactive features and dynamic content.
- Visual Studio Code as my development environment.
- GitHub for sharing and managing my project.

What I Learned

Working on CyberShield helped me practise JavaScript arrays and objects, DOM manipulation, event listeners, search and filtering logic, and form validation.

It also helped me understand how HTML, CSS, and JavaScript work together to turn a static webpage into an interactive website.

I am still learning, and I see this project as another step towards becoming better at both frontend development and cybersecurity.

How to Run It

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your browser, or use the Live Server extension.
4. Explore the different sections and test the interactive features.

What's Next?

I plan to keep improving the project by adding more cybersecurity topics, expanding the quiz, improving the user experience, and exploring how a secure backend could support more advanced features in the future.

Disclaimer

CyberShield is an educational project. It does not perform real-time threat detection, scan systems for vulnerabilities, or send incident reports to a security team. The password checker is a basic demonstration and should not be used as a complete security assessment.
